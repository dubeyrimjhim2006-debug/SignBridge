SIGNBRIDGE / GOOGLE MEET

Live subtitles
for Google Meet.

Install the SignBridge Chrome extension to show live English subtitles over a Google Meet lecture.

Download SignBridge extension

How to install

  1. Click Download SignBridge extension above.
  2. Extract the downloaded signbridge-extension.zip file.
  3. Open chrome://extensions in Google Chrome.
  4. Enable Developer mode using the switch in the top-right corner.
  5. Click Load unpacked.
  6. Select the extracted extension folder.
  7. Open Google Meet in a new tab.
  8. Click the SignBridge extension icon.
  9. Click Start subtitles.

Important: During development, Chrome requires the Load unpacked installation method. A normal one-click installation can be provided after publishing SignBridge to the Chrome Web Store.
